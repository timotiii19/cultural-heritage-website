# Backup before restoring the original visual design

These files retain the simplified Arts page before it was replaced with the original exhibition layout and navigation improvements.

To return to the original exhibition design without the new navigation adjustments, use the existing `design-backups/arts-before-cohesive/Restore-ArtsDesign.cmd`. That restores the exact original Arts page, including the previously requested photo-number and source-link removals.

The current Arts page uses `arts.css` plus `arts-navigation.css`. The shared reference styles, research data, and images are unchanged.
